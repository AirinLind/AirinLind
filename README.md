### Чем занимаюсь

Frontend-разработчик с коммерческим опытом на **React** и **TypeScript**. Специализируюсь на сложных интерфейсах: динамические формы, таблицы с фильтрацией, интеграции с REST и GraphQL API. Работала и в команде над крупным EdTech-продуктом, и самостоятельно — над SPA с нуля.

Из последнего: переписала поиск в админке на пагинированный — сервер стал отвечать на 30% быстрее, а таблица перестала подвисать. Мелочь, а пользоваться стало приятно.

### Проекты

**EduCollab** — платформа для проектного обучения
Роли (студент / преподаватель / ментор), команды, CRUD проектов, оценка с защитой от повторного голосования, прогресс через milestones. Серверное состояние — на React Query.
`React 18` `TypeScript` `React Query` `Context` `SCSS`
→ [github.com/AirinLind/EduCollab-Platform](https://github.com/AirinLind/EduCollab-Platform)

**MyFeed** — соцсеть на GraphQL
JWT-авторизация, лента с сортировкой по свежести и популярности, лайки, загрузка картинок в S3. Собрана по FSD, чтобы новые фичи не превращались в кашу.
`React` `TypeScript` `Apollo` `GraphQL` `FSD` `Vite`
→ [github.com/AirinLind/my-feed-react](https://github.com/AirinLind/my-feed-react)

**Trello Clone** — канбан-доска
Глобальный стор на Redux Toolkit, селекторы через Reselect, доска переживает перезагрузку страницы благодаря redux-persist. Формы — на react-hook-form.
`React` `TypeScript` `Redux Toolkit` `Reselect` `RHF`
→ [github.com/AirinLind/trello-react-ts](https://github.com/AirinLind/trello-react-ts)
